# Cosmetics E-commerce Big Data Dashboard

Streamlit dashboard for the Big Data Case Study:

**Customer Shopping Behavior Analysis in an Online Cosmetics Store Using Big Data**

## Architecture

- **Google Colab + PySpark:** data processing, funnel analysis, product/brand analysis, K-Means.
- **GitHub:** stores the Streamlit source code and result CSV files.
- **Streamlit Community Cloud:** deploys the interactive dashboard.

The Streamlit app does **not** install PySpark. It reads the final CSV outputs generated by the Colab analysis, which keeps deployment lightweight.

## Files

- `app.py` — Streamlit application
- `requirements.txt` — Python dependencies
- `result_*.csv` — full-dataset analysis outputs

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

1. Create a public GitHub repository.
2. Upload all files in this folder.
3. Go to Streamlit Community Cloud.
4. Connect GitHub.
5. Create an app and select:
   - Repository: your repository
   - Branch: `main`
   - Main file: `app.py`
6. Deploy.
